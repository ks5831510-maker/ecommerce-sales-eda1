# E-commerce Sales Performance & EDA Project

## Overview
Exploratory Data Analysis on Superstore Sales Dataset using Python, Pandas, Matplotlib, and Seaborn.

## Key Insights
* **Top Revenue Driver:** Technology category generated the highest sales revenue.
* **Peak Season:** November and December saw the highest sales volume due to seasonal demand.
* **Customer Demographics:** Individual consumers contributed ~51% of total sales, followed by Corporate clients (30.4%).
* **Top Markets:** Highest sales generated from major urban hubs including New York City and Los Angeles.

## Tech Stack
* Python
* Pandas
* Matplotlib & Seaborn
* Jupyter Notebook
